# AITask CLI Error Codes (BE-130 / BE-127)

标准 21 个错误码：

1. PROJECT_NOT_FOUND
2. PROJECT_ACCESS_DENIED
3. AGENT_NOT_BOUND_TO_PROJECT
4. AGENT_TOKEN_INVALID
5. AGENT_TOKEN_EXPIRED
6. TASK_NOT_FOUND
7. TASK_NOT_ELIGIBLE_FOR_AGENT
8. TASK_ALREADY_DELEGATED
9. TASK_NOT_ASSIGNED_TO_CURRENT_AGENT
10. TASK_ACTIVE_RUN_MISMATCH
11. TASK_DEPENDENCY_NOT_DONE
12. TASK_STATUS_INVALID
13. ROOM_NOT_FOUND
14. ROOM_ACCESS_DENIED
15. ROOM_MESSAGE_TOO_LARGE
16. CONTEXT_BUDGET_EXCEEDED
17. CONTEXT_HANDOFF_REQUIRED
18. HANDOFF_NOT_FOUND
19. HANDOFF_ALREADY_CONSUMED
20. OPENVIKING_WRITE_FAILED
21. OPENVIKING_READ_FAILED

CLI 展示规范：

- 始终输出 `Error [CODE]: 中文提示`
- 若有推荐动作，追加 `下一步: <command>`
- 错误映射实现见 `backend/internal/cli/error_help.go`
